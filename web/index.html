Telegram Voice Chat Player

Music, in your group.

YoriMusic streams high-quality audio and video straight into Telegram group voice chats — with queues, inline controls and a full moderation toolkit built in.

Join the Group Our Channel

Free & open source · MIT licensed

What it does

Audio & video playback

Stream into voice chats with /play and /vplay. Sources include YouTube, Spotify, Apple Music, SoundCloud, Resso, M3U8 live streams and Telegram files.

Real queue control

Auto-play, loop, shuffle, seek, skip-to-track and replay — driven by inline buttons instead of remembering commands.

Moderation built in

Admin-only playback, authorised users, sudo tiers, chat blacklisting, global bans and clean-mode auto-deletion.

13 languages

Arabic, German, English, Spanish, French, Hindi, Japanese, Burmese, Punjabi, Portuguese, Russian, Turkish and Chinese.

Generated thumbnails

Every track gets a rendered now-playing card with artwork, title, channel and a progress bar.

Scales with you

Up to three assistant accounts, auto-leave on idle voice chats, duration limits and owner broadcast tools.

Commands

/play /vplayPlay audio or video from a query, URL or replied media
/pause /resume /skip /stopPlayback controls
/seek /loop /shuffleSeek, loop and shuffle the queue
/queue /playingView the queue or the current track
/settingsAdmin-only mode, clean-mode and language
/auth /blacklistchatAuthorised users and chat blocking
/addsudo /delsudoManage sudo users (owner only)
/broadcast /stats /restartOwner tools

Run /help in the bot for the full localised menu.

Run your own

Self-host in a couple of minutes. You'll need Telegram API credentials, a bot token, a MongoDB URL and a Pyrogram string session.

git clone https://github.com/harshi79/YoriMusicBot.git
cd YoriMusicBot
cp sample.env .env   # fill in your values
docker build -t yorimusic .
docker run -d --env-file .env -p 8080:8080 yorimusic
